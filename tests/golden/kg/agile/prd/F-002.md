# F-002 — §2.2  用户登出



## Narrative

### §2.2 F-002 用户登出

允许已登录用户终止当前会话，清空客户端 token。

#### AC-002 一键登出清空 token

调用 logout 接口返回 204；客户端本地 token 被擦除。
