# 框架审查后的两次迭代任务提示词

本目录基于上级目录 [`../`](..)（`framework-audit-2026-05`）四份审查报告，规划出**两次串行的动态工作流（dynamic workflow）迭代任务**的提示词。第二次以第一次的产出（已加固的纯净基点）为前置。

| 序 | 提示词 | 主题 | 前置 |
|----|--------|------|------|
| 1 | [`task-1-baseline-hardening.md`](task-1-baseline-hardening.md) | 架构优化 / 代码重构 / 缺陷修复 → 纯净基点 | 无 |
| 2 | [`task-2-strategic-evolution.md`](task-2-strategic-evolution.md) | 架构与功能特性战略演进 → 增量开发 | 任务 1 完成并合入 |

## 使用方式

1. 在仓库根新开一个 Claude Code 会话。
2. 将对应提示词正文整体粘贴为会话首条指令，并保留其中的 `workflow` 关键词以显式开启多智能体动态工作流。
3. 提示词自包含：项目指令文件（`CLAUDE.md` / `.claude/rules/COMMON-RULES.md` / `.claude/rules/SUB-AGENT-PROTOCOLS.md`）会被新会话自动加载，提示词只补充任务级上下文，不重述已自动加载的纪律。

## 设计约定

两次任务都**不预设**具体修复方案或实现计划。提示词只界定**任务目标 / 范围边界 / 工作原则 / 方法学 / 完成定义**；逐条核实结论、修复计划、增量设计与落地由各自的动态工作流在执行时自行产出——审查报告里既有的「建议」字段只作为起点假设，不作为判决。
