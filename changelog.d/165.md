### Changed

- **`cataforge penpot deploy` 默认 image tag 改 `2.15` + `PENPOT_IMAGE_TAG` env override** —— 把 compose 模板里 4 处硬编码 `penpotapp/*:latest` 改成 `:{image_tag}` 占位符；`get_config()` 新增 `image_tag = os.environ.get("PENPOT_IMAGE_TAG", DEFAULT_PENPOT_IMAGE_TAG)`，默认 `"2.15"`。`latest` 漂移过去就坑过用户 —— 2.15 frontend 加了 nginx upstream `penpot-mcp` 硬解析，没新增 penpot-mcp 服务的话容器起来就 `host not found in upstream` 退出。

- **compose 模板加 `penpot-mcp` 服务 + 移除 `disable-mcp` workaround** —— 2.15 frontend 默认就要这个 upstream，原来用 `disable-mcp` flag + `PENPOT_MCP_URI=http://127.0.0.1` 占位"骗"nginx 跳过 MCP 路由的方案不再需要：直接把 `penpotapp/mcp:{image_tag}` 起为内部 compose 服务，frontend `depends_on` 加上 `- penpot-mcp` 即可。

- **`cmd_doctor` compose 检查改读 penpot-mcp 服务 + image_tag pinning** —— 老的 sentinel 是字符串 `disable-mcp` 和 `PENPOT_MCP_URI`，现在改成 `penpot-mcp:` 服务存在 + `:{image_tag}` 出现（fall back 走 `cataforge penpot deploy --force-recreate` 重写）。

- 配套测试 `tests/integrations/test_penpot.py` 3 个用例改写：`test_compose_template_disables_mcp_routing` → `test_compose_template_declares_penpot_mcp_service`（断言新模板含 4 个 `penpotapp/*:DEFAULT_PENPOT_IMAGE_TAG` 镜像 + 含 penpot-mcp 服务）；`test_image_tag_env_override` / `test_image_tag_default_when_env_unset` 新增覆盖 env 覆盖路径；doctor 两个 cmd_doctor 用例 sentinel 同步迁移。
