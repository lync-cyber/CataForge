### Added

- **KG-first 文档系统（design [`docs/research/kg-feature-upgrade-design.md`](docs/research/kg-feature-upgrade-design.md)）** —— 引入 RDF/OWL/SPARQL/SHACL 栈作为文档 source of truth；markdown 由 KG 渲染生成。新增 `cataforge kg *` 顶层命令组（init / migrate / query / validate / add-entity / get-entity / update-entity / delete-entity / add-relation / remove-relation / ingest / export / render / coverage / template-lint / infer / impact / explain / viz / conflicts / resolve / adapter [list/show/context/write-back] / adapter-migrate / benchmark）。完整使用 cookbook 见 [`docs/reference/kg-cookbook.md`](docs/reference/kg-cookbook.md) 与 [`docs/reference/kg-sparql-recipes.md`](docs/reference/kg-sparql-recipes.md)。
- **KGAdapter 抽象层** —— `src/cataforge/kg/adapters/` 提供 6 个内置 adapter（feature_authoring / module_implements / task_decompose / test_validates / doc_read / ui_renders），通过 SKILL/AGENT frontmatter 中的 `kg_adapter:` 块声明式配置。`cataforge kg adapter-migrate` 一次性批改 24 个 frontmatter + 写出 5 个默认 JSON Schema（幂等）。
- **Plugin 注册机制** —— `.cataforge/framework.json` 的 `kg.plugins` 列表支持 6 类 Protocol（StoreBackendPlugin / ReasoningEnginePlugin / IngestPlugin / RenderTargetPlugin / QueryDSLPlugin / KGAdapterPlugin）。示例 `cataforge.kg.store_oxigraph` 为 oxigraph 后端的参考实现，pip 装 `cataforge[oxigraph]` 即可启用。
- **PostToolUse auto-ingest hook** —— `docs/**/*.md` 编辑后自动调 `cataforge kg ingest --auto`（quiet-fail，不阻断 LLM）；累积冲突在 `docs/.doc-graph/conflicts/` 排队，由 `cataforge doctor` / `cataforge kg conflicts` / `cataforge kg resolve` 处理。
- **CI gates** —— pre-commit 与 PR CI 新增 `kg template-lint` / `kg render --check` / `kg validate` / `kg benchmark`（perf-budget gate，warn-only）。

### Changed

- **doctor** —— 新增 KG 健康检查（pending conflicts → FAIL；SHACL 不合规 → FAIL；render drift → FAIL）。
- **`scripts/checks/check_no_design_residue.py`** —— 新增 `<!-- allow-kg-migration: ... -->` 窄边界 escape hatch，仅供本次 KG cutover PR 使用；v0.5 cutover 后批量清除。
- **`src/cataforge/docs/migrate_nav.py` 与 `migrate_review_frontmatter.py`** —— 迁移到 `src/cataforge/core/migrate/`（这俩是项目状态迁移工具，不属于 docs-index 老底）。`cataforge docs migrate-nav` 与 `cataforge docs migrate-reviews` CLI 入口不变。

### Deprecated

- **`cataforge docs index/load/validate/reverse-deps`** —— 仍可用作 backward-compat alias，但官方推荐改用 `cataforge kg ingest --all` / `cataforge kg query` / `cataforge kg validate` 等 KG-first 等价命令。v0.5 cutover 时会下线 `cataforge.docs.indexer` 与 `cataforge.docs.loader`。
